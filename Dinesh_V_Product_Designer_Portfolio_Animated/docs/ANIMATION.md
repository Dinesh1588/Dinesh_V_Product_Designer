# Animation map

The portfolio is dark-first and animation-led, but motion is used to communicate hierarchy rather than decorate every element.

1. **Hero reveal** — GSAP text and visual entrance.
2. **Interactive WebGL hero** — procedural Three.js wireframe / particles reacting to pointer movement.
3. **Magnetic actions** — pointer-aware buttons.
4. **Custom cursor** — desktop only; becomes VIEW/MOVE over interactive areas.
5. **Scroll reveals** — sections enter progressively with ScrollTrigger.
6. **Process line** — scroll-driven progress through Understand → Define → Explore → Design → Build & Refine.
7. **Project tilt/parallax** — image and card movement follows pointer position.
8. **Marquee** — continuous product-thinking keywords.
9. **Playground motion** — CSS orbital / interface studies.
10. **Reduced motion** — `prefers-reduced-motion` disables intensive motion and WebGL.

Rive and Lottie dependencies are included for approved real assets. No fake `.riv` or `.json` animation is shipped.
